                The X-Forwarded-Prefix HTTP Header Field
                 draft-bkayranci-x-forwarded-prefix-00

Abstract

   This document specifies the X-Forwarded-Prefix HTTP header field, a
   widely deployed de-facto standard used by reverse proxies, API
   gateways, load balancers, and ingress controllers to convey the
   original URI path prefix that was stripped before forwarding a
   request.
